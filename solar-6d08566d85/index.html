Output against its own past

The vertical axis is one month's output as a percentage of what this same array would have produced in the same weather when the record began. Both sides of that division are kWh, so the percentage has no units of its own — it is a comparison, not a quantity: this month  =  612 kWh actually produced
baseline    =  606 kWh the array would have made in the same sun and heat
plotted    =  612 ÷ 606  =  101% Because the same weather appears on both sides, a dull month does not count against the panels — only the array itself can move this number. 100% means nothing has changed; below means the array is producing less than it used to for the same sun.

How to read it. The shaded band is one standard deviation of this site's own month-to-month scatter. Inside it, a month is indistinguishable from normal. One point below is noise; two or three in a row below the band is a signal — soiling, snow, shade that has grown, or a string offline. A jump back up usually means rain or a wash.

What it will not tell you. Panel ageing runs about 0.5% a year, far below the monthly scatter, so this cannot show gradual decline for a year or two yet. It is a fault detector, not a degradation meter — and an alert fires if two complete months fall below 90%.

Against the utility meter

Net grid here is computed, not measured: these CTs sit on the wrong side of the solar tie-in, so every consumption figure is reconstructed in software. The meter is the only instrument in this system not derived from the PVS6, which makes it the only independent check there is. difference  =  our net grid  −  the utility's net grid
